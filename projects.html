IoT Smart Home Dashboard

A real-time environmental monitoring system that collects temperature, humidity, and motion data from ESP32 microcontrollers via MQTT and displays live sensor readings on a responsive web dashboard.

  • Live sensor readings streamed over the MQTT protocol
  • Historical trend charts with Chart.js integration
  • Threshold alerts for temperature and humidity spikes
  • Mobile-responsive dashboard with Flask backend

Drone Mission Planner

A browser-based tool for planning and visualising autonomous drone waypoint missions over interactive satellite maps, designed for ArduPilot-compatible UAVs with altitude profiles and obstacle zones.

  • Click-to-add waypoints on a live Leaflet.js satellite map
  • Automatic total distance and estimated flight time calculation
  • Altitude and speed settings configurable per waypoint
  • Export to JSON / KML for use with Mission Planner

Crop Health Aerial Monitor

An image-processing pipeline that analyses aerial images captured by drones to compute vegetation indices (NDVI) and detect early crop stress indicators, supporting precision agriculture in Nigeria.

  • NDVI computation from multispectral drone imagery
  • False-colour heatmap generation for stress zone detection
  • Annotated field health reports with zone mapping
  • REST API for integration with drone ground station software
